Introduction

In this section, we will demonstrate how one may train a machine learning model and tune its hyper-parameters using the tidymodels framework. For more information, click this link.

We will combine tidymodels with H2O. H2O is an open-source, distributed machine learning platform designed for scalable and fast data analysis. It’s widely used for building predictive models on large datasets and supports both traditional machine learning algorithms and modern AI methods.

Next, we will create a data preprocessing recipe using the recipes package. This recipe will:

  • Drop zero and near zero-variance columns.
  • Normalise all numeric columns using Z-standardisation.
  • Impute missing data using k nearest neighbor imputation.
training_recipe <- recipe(data_train) |>
  update_role(everything(), new_role = "predictor") |>
  update_role(mpg, new_role = "outcome") |>
  step_zv() |>
  step_nzv() |>
  step_normalize(all_numeric(), -all_outcomes()) |>
  step_impute_knn()

The generalised linear models (GLMs) and gradient boosting machine (GBM) algorithms show promising results. We can next visualise the stacking ensemble member weights from H2O’s AutoML algorithm.

p <- auto_fit |>
  extract_fit_parsnip() |>
  member_weights() |>
  unnest(importance) |>
  filter(type == "scaled_importance") |>
  ggplot() +
  geom_boxplot(aes(value, algorithm)) +
  scale_x_sqrt() +
  labs(y = NULL, x = "scaled importance", title = "Member importance in AutoML model")

ggplotly(p)

This plot shows that the GLM and GBM models are more heavily weighted in the ensemble than the other supported algorithms.

Uncertainty Quantification

Our AutoML model does not produce prediction intervals out-of-the-box. Hence, no in-built uncertainty quantification. We will use probably to conformalise the model to produce non-parametric prediction intervals using conformal inference.

patched_stack_regressor <- tidymodels_deployment$patch_tidymodel(auto_fit, training_recipe, data_train)
conformalised_regressor <- int_conformal_split(patched_stack_regressor, data_train)
conformalised_regressor$training <- data_train

We can view the predictions produced by the conformalised model, this time with prediction intervals included:

Predicted and observed Miles per Gallon for testing set using conformalised model (95% prediction intervals).

Most of the testing observations fall within the 95% prediction intervals. Given a large enough testing dataset, we would expect roughly 5% of new observations to fall outside of the intervals.

Model versioning, sharing, and deployment

Finally, we will demonstrate how to perform model versioning, sharing, and deployment using a combination of pins, vetiver, and plumber. In this example, we will first save our AutoML model to a local temporary directory using pins and vetiver

board <- board_temp()
v_model <- vetiver_model(conformalised_regressor, "automl_model")
vetiver_pin_write(v_model, board = board)

loaded_v <- board |> 
  vetiver_pin_read("automl_model")

pr(here("app", "api", "plumber.R")) |>
  vetiver_api(loaded_v) |>
  pr_run(port = 8088)
